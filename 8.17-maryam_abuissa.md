# Example notes

These are example notes, courtesy of your instructor Professor Abuissa. 

**Instructions:** 
1. fork this Github repository (look in the top right above `<> Code`)
2. create, edit, and commit your Markdown file in _your_ branch
     1. title your notes `month.day-firstname_lastname.md`
4. create a pull request
5. I will review your file and email you about revisions, or otherwise merge it

A couple of suggestions:
- use "-" or "*" to make lists
- toggle between `Edit` and `Preview` in GitHub to see what your notes will look like to others
- use "#" to make a header (more hashtags, like "##," creates a subheader)
- use "**" on each side of an expression to **bold** it (one "*" *italicizes*, as does "_")
- use "$$" on each side of an expression for $$\LaTeX$$ formatting
- for other markdown syntax details, visit this [guide](https://www.markdownguide.org/).
